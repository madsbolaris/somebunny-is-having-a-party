# MTG Commander Reference Decks

## Purpose

This document provides **reference deck examples** at each power level tier to help calibrate evaluations. Use these as anchor points when assessing decks—compare your evaluation to these known quantities to ensure consistency.

Each reference deck includes:
- Complete evaluation using the three-phase rubric
- Quantitative scores for all metrics
- Final power level rating with justification
- Key characteristics that define its tier

## Power 2: Unmodified Precon

**Deck Name**: Draconic Dissent (Unmodified 2023 Precon)

**Commander**: Firkraag, Cunning Instigator

**Archetype**: Dragon Tribal / Goad

---

### Phase 1: Strategy Summary

"This deck uses Firkraag to goad opponents' creatures and generate card advantage when they attack each other. The primary win condition is combat damage through flying dragons, with no clear backup plan. Expected win turn is 18-20 if the game goes uncontested. Firkraag is important but the deck lacks ways to protect him or recover if he's removed repeatedly."

**Average Win Turn**: 19

---

### Phase 2: Component Scores

| Category | Score | Notes |
|----------|-------|-------|
| Speed | 1 | Wins turn 19, extremely slow |
| Mana Base Quality | 2 | 40 lands, all basics and tap lands except Command Tower |
| Fast Mana Density | 2 | Sol Ring only |
| Card Draw | 2 | 2 sources (Trouble in Pairs, Dragon's Hoard) |
| Interaction | 2 | 2 pieces (Chaos Warp, Decimate), both sorcery speed |
| Synergy | 3 | 25% Tier 1-2 (dragons synergize, but many filler cards) |
| Threat Density | 2 | 1 win condition (dragon beatdown), no tutors, no backup |
| Resilience | 1 | No protection, no recursion |

**Quantitative Base Score**: (1×0.2) + (2×0.15) + (2×0.1) + (2×0.15) + (2×0.15) + (3×0.1) + (2×0.1) + (1×0.05) = **1.95**

---

### Phase 3: Final Assessment

**Qualitative Adjustments**: None (this is baseline precon)

**Final Power Level**: **2/10**

**Tier**: Preconstructed/Beginner

---

**Key Characteristics**:
- No clear closing strategy
- Minimal interaction (can't stop opponents)
- Extremely slow (turn 18+)
- All tap lands and basics
- No tutors, minimal card draw
- Fragile (no protection or recursion)

**Strengths**:
1. Teaches fundamental Commander gameplay
2. Firkraag's goad ability creates interesting politics
3. Dragons are fun and thematic

**Weaknesses**:
1. Too slow to compete with modified decks
2. Cannot answer threats effectively
3. Runs out of gas quickly with only 2 draw sources

## Using Reference Decks for Calibration

### How to Use These Examples

1. **Before Evaluating**: Read through the reference decks to understand what each power level looks like in practice.

2. **During Evaluation**: As you evaluate a deck, mentally compare it to the closest reference deck:
   - "Is this deck faster or slower than the Power 6 Edgar Markov?"
   - "Does this deck have more or less interaction than the Power 7 Kinnan?"
   - "How does the mana base compare to the Power 8 Gitrog?"

3. **After Evaluation**: Double-check your rating against the reference decks:
   - If you rated a deck Power 7, does it actually feel like the Kinnan example?
   - If not, adjust accordingly

4. **Calibrating with Other Evaluators**:
   - Evaluate one of these reference decks yourself
   - Compare your scores to the provided evaluation
   - Discuss any discrepancies to align understanding
   - Repeat with another reference deck until you're consistently aligned

### Common Calibration Issues

**Issue**: "I keep rating decks higher than the reference examples."
- **Solution**: You may be over-weighting a single strong element (e.g., one powerful card). Re-read the tier definitions and focus on holistic assessment.

**Issue**: "My quantitative scores match, but my qualitative assessment differs."
- **Solution**: Ensure you're applying the same qualitative standards. Discuss specific examples with other evaluators.

**Issue**: "I'm not sure how to rate stax/group hug/chaos decks."
- **Solution**: See [FAQ.md](FAQ.md) for archetype-specific guidance. These archetypes often require subjective judgment.

### Creating Your Own Reference Decks

If your local meta has well-known decks that everyone understands:

1. Evaluate 1-2 decks from each power tier using the rubric
2. Document the evaluations thoroughly
3. Share with your playgroup as local reference decks
4. Use these alongside the provided examples for calibration

This creates shared understanding within your community.
